## Why

지금은 기록을 수정해도 화면에는 여전히 최초 저장 시각만 보인다. 언제 마지막으로 고쳤는지 알 수 없어 최초 작성 시간과 최종 수정 시간을 구분해서 보여줄 필요가 있다.

## What Changes

- 각 기록에 최종 수정 시각(`updatedAt`)을 별도로 저장한다
- 텍스트가 실제로 바뀐 저장에서만 `updatedAt`을 현재 시각으로 갱신한다 (같은 텍스트로 "저장"해도 갱신하지 않음)
- 목록 항목에 "작성"과 "최종 수정" 시각을 구분해서 표시한다
- 아직 한 번도 수정하지 않은 기록은 "최종 수정" 자리에 "수정한 내역이 없습니다."를 표시한다

## Capabilities

### New Capabilities
(없음)

### Modified Capabilities
- `diary-edit`: 저장 시 텍스트 변경 여부에 따라 최종 수정 시각을 기록하는 동작이 추가된다.
- `diary-write`: 목록 항목에 작성 시각과 최종 수정 시각(또는 미수정 안내 문구)을 함께 표시하도록 목록 표시 요구사항이 변경된다.

## Impact

- `app.js`: 기록 데이터에 `updatedAt` 필드 추가, 저장 시 텍스트 변경 여부 비교 로직 추가, 목록 렌더링에 최종 수정 시각/안내 문구 표시 추가
- 기존 기록(旧 레코드)에는 `updatedAt`이 없으므로 하위 호환 처리 필요
