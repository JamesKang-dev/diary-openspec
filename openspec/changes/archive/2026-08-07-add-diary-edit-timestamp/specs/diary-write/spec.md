## MODIFIED Requirements

### Requirement: 최근 기록 목록 표시
시스템은 저장된 기록을 최신순으로 정렬하여 목록으로 표시해야 하며(SHALL), 기본으로 최근 5개가 보이고 5개를 초과하는 기록은 스크롤을 통해 확인할 수 있어야 한다(SHALL). 각 항목에는 최초 작성 시각과 최종 수정 시각을 구분하여 표시해야 하며(SHALL), 한 번도 수정되지 않은 기록은 최종 수정 시각 자리에 "수정한 내역이 없습니다."를 표시해야 한다(SHALL).

#### Scenario: 기록이 5개 이하인 경우
- **WHEN** 저장된 기록이 5개 이하이다
- **THEN** 시스템은 저장된 모든 기록을 최신순으로 목록에 표시한다

#### Scenario: 기록이 5개를 초과하는 경우
- **WHEN** 저장된 기록이 5개를 초과한다
- **THEN** 시스템은 목록 영역에서 최신 기록이 상단에 오도록 표시하고, 스크롤을 통해 5개를 초과하는 이전 기록도 확인할 수 있게 한다

#### Scenario: 수정된 적 없는 기록 표시
- **WHEN** 목록에 아직 한 번도 수정되지 않은 기록이 있다
- **THEN** 시스템은 해당 항목의 최종 수정 시각 자리에 "수정한 내역이 없습니다."를 표시한다

#### Scenario: 수정된 적 있는 기록 표시
- **WHEN** 목록에 한 번 이상 수정된 기록이 있다
- **THEN** 시스템은 해당 항목에 최초 작성 시각과 최종 수정 시각을 함께 표시한다
