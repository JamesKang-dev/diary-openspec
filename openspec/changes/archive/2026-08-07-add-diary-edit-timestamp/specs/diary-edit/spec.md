## MODIFIED Requirements

### Requirement: 기록 인라인 수정
시스템은 목록의 각 기록 항목에 수정 버튼을 제공해야 하며(SHALL), 수정 버튼 클릭 시 해당 항목의 텍스트를 입력 필드로 바꿔 수정할 수 있게 해야 한다(SHALL). 저장 시 해당 기록의 텍스트만 갱신해야 하며(SHALL), 날짜 및 저장 시각(정렬 기준)은 변경하지 않아야 한다(SHALL). 저장한 텍스트가 기존 텍스트와 실제로 다를 경우에만 최종 수정 시각을 현재 시각으로 갱신해야 한다(SHALL).

#### Scenario: 수정 버튼 클릭 시 인라인 편집 진입
- **WHEN** 사용자가 목록의 한 항목에서 수정 버튼을 클릭한다
- **THEN** 시스템은 해당 항목의 텍스트를 입력 필드로 표시하고 저장/취소 버튼을 보여준다

#### Scenario: 수정 내용 저장
- **WHEN** 사용자가 인라인 입력 필드의 텍스트를 변경하고 저장 버튼을 클릭한다
- **THEN** 시스템은 해당 기록의 텍스트를 새 값으로 갱신하고, 날짜·저장 시각은 그대로 유지하며 목록에서의 순서를 바꾸지 않는다

#### Scenario: 수정 취소
- **WHEN** 사용자가 인라인 편집 중 취소 버튼을 클릭한다
- **THEN** 시스템은 텍스트를 원래 값으로 되돌리고 인라인 편집을 종료한다

#### Scenario: 빈 값으로 수정 저장 시도
- **WHEN** 사용자가 인라인 입력 필드를 비운 상태에서 저장 버튼을 클릭한다
- **THEN** 시스템은 기록을 갱신하지 않고 인라인 편집 상태를 유지한다

#### Scenario: 텍스트를 실제로 변경하고 저장
- **WHEN** 사용자가 기존 텍스트와 다른 내용으로 수정하고 저장 버튼을 클릭한다
- **THEN** 시스템은 해당 기록의 최종 수정 시각을 현재 시각으로 갱신한다

#### Scenario: 텍스트를 바꾸지 않고 저장
- **WHEN** 사용자가 인라인 편집에서 텍스트를 바꾸지 않은 채 저장 버튼을 클릭한다
- **THEN** 시스템은 최종 수정 시각을 갱신하지 않는다
