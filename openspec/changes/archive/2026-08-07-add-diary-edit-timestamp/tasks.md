- [x] 1.1 `handleEditSave`에서 저장 전 텍스트(trim)와 새 텍스트(trim)를 비교하는 로직 추가
- [x] 1.2 텍스트가 실제로 다를 때만 `updatedAt`을 현재 시각(epoch ms)으로 갱신
- [x] 1.3 텍스트가 동일하면 `updatedAt`을 변경하지 않음

## 2. 표시 로직

- [x] 2.1 `updatedAt`이 있는 기록은 `formatDate`/`formatTime`으로 최종 수정 시각 문자열 생성
- [x] 2.2 `updatedAt`이 없는 기록은 "수정한 내역이 없습니다." 표시
- [x] 2.3 목록 항목에 작성 시각과 최종 수정 시각(또는 안내 문구)을 구분해서 렌더링

## 3. 검증

- [x] 3.1 텍스트를 실제로 바꿔 저장 시 최종 수정 시각이 갱신되는지 확인
- [x] 3.2 텍스트를 바꾸지 않고 저장 시 최종 수정 시각이 갱신되지 않는지 확인
- [x] 3.3 한 번도 수정하지 않은 기록에 "수정한 내역이 없습니다."가 표시되는지 확인
